# 共享钱包

部署前执行 Schema 58 迁移。默认 internal，原本地余额、支付、兑换和奖励保留。external 读取小洞AI会员钱包；充值在小洞AI进行，Canvas 不复制余额、不回退花本地积分。

## 配置与身份

管理员 GET/PUT `/api/admin/wallet-settings`：`mode`、`baseUrl`、`clientId`、`siteId`、`issuer`、`rechargeUrl`、`version`；写入可带 `clientSecret`，空值保留密钥。读取仅返回 `secretConfigured`。密钥使用系统设置加密器保存，审计不记录密钥。保存使用版本比较；启用前必须已有该 issuer/site 的 Cloooud SSO 会员，服务端以该会员执行只读余额探测。

SSO 仅绑定身份。外部会员由 `cloooud` identity 的 issuer 摘要、站点 ID、会员 ID 解析，不按昵称、邮箱猜测。`GET /api/wallet` 增加 `walletMode`、`rechargeUrl`，每次请求远端余额；远端失败返回错误。公共 feature flags 在 external 强制 `creditsEnabled=true`，同时附带钱包模式。

管理端功能接口的顶层字段仍返回当前有效状态，另提供 `configuredFeatures` 保存的内部策略。后台编辑和局部保存以该策略为基底，全局用户界面继续使用顶层有效状态；不把外部模式强制开启的值写回内部策略。切回内部后恢复原开关，内部模式仍可正常修改。

后端与前端应一起发布，并刷新已打开的旧管理页面。旧版页面没有区分有效值和保存值，不能继续拿旧响应整包保存；新版在外部模式遇到缺少 `configuredFeatures` 的旧后端时会阻止编辑。

前端首次进入、钱包更新事件、窗口获得焦点及页面重新可见时刷新公共功能和余额，按当前用户同步报价。多个消费者共享刷新；后续事件取消过时请求，用户切换后的旧响应不能覆盖新状态。没有常驻轮询，页面持续前台且没有事件时不会立即发现后台切换。平台整积分文案只用于系统模型，自定义用户渠道保留原显示规则。

相同功能值或无关功能的刷新不会丢弃在途余额；真实钱包模式、积分开关、充值地址或用户变化仍使旧请求失效。余额响应合并新钱包信息时保留同时更新的其他功能。

同账号的资料或头像更新保留当前会话，余额查询可继续完成；真正登录、退出或切换账号会更新会话版本。余额、资料和公共功能的迟到响应不能跨会话写入，包括退出后以同一账号重登和A→B→A切换。

外部模式禁止本地支付建单、签到、兑换、批次创建和管理员调账；注册奖励记录唯一的零金额跳过标记，登录不中断，切回内部后不补发。停用兑换码和查询历史记录仍可用于管理旧数据。

## 计费与恢复

每单按 `ceil(microcredits / 1000000)` 换算整数积分，报价与预扣一致；批量按各子任务分别取整。任务入队先保存账单来源、配置版本、加密凭据快照和 reserve 操作；`walletState=pending` 表示尚未确认预扣。worker 及同步代理在调用模型前确认远端预扣。远端余额不足直接失败，不调用模型。

Token上限校验、价格计算和整分换算使用同一钱包配置快照。报价期间模式或配置版本变化时，预留入口拒绝旧版本，不允许把内部估算金额当作新外部授权使用。

任务成功以实际金额 settle；失败 refund；已退款任务恢复成功走原钱包 restore。更便宜的备用线路保留原预扣总额，最终结算退差价；更贵且超过原授权的线路不自动启用。内部免费同步代理也记录零价账单，避免执行期间切换模式；关闭内部积分后，历史恢复扣费形成的负余额不会阻止免费调用，正金额请求仍校验余额。

同一操作重试保持 operation ID、金额和来源不变，每次重新生成签名 nonce。未知结果保持 pending/uncertain；自动对账每 30 秒处理已尝试的预扣及待结算/退款，不提前扣除未开始的排队任务。管理员可 POST `/api/admin/wallet-reconcile` 触发同一对账。状态查询不能替代操作收据，查询后仍重放原操作。成功收据余额是历史快照，展示余额必须重新查 balance。

预扣回执和进入执行状态都在事务内锁定关联任务并核对当前账单归属。取消或停止后的迟到预扣只确认原操作，账单保留 `uncertain`，不再进入模型执行，未核清前禁止重试。此状态需要核对原执行证据，不根据取消状态自动退款；正常活动任务的预扣超时恢复及同步代理保持原行为。

核账每批最多50笔，按最久未处理的账单轮转并跳过有效处理锁；凭证损坏的旧单不会永久占满每批。管理员重试余额不足的恢复操作同样轮转。该排序沿用现有持久时间戳，无新增数据库迁移。

小洞AI原单退款支持已软删除账户，仍拒绝该账户的新扣费。小洞AI新增持久提交冻结与 `credit-hold-v1` 网关回执：提交前冻结、确认受理后正式扣费、明确未提交才释放。Canvas 的 balance、预扣和退款余额均排除小洞AI尚未结算的冻结；Canvas已有 reserve 已实际扣款，不重复纳入冻结。

启用前需在小洞AI会员库新增 `hthot_point_hold`、实际 ht_api 网关库新增 `htapi_submission`，先升级网关，再统一升级所有会员扣费节点并启用提交恢复任务。旧网关不支持回执时，新本地生成会在派发前拒绝。第三方结果未知保留冻结；进程中断后的部分业务作品关联仍需依据原结果人工补录，不会自动重跑模型。迁移及预发布真实链路验收仍需在部署环境完成。

恢复扣费明确因余额不足被拒绝时保留 refunded，充值后可重新恢复同一操作。超时不等同于失败退款。实际费用超过原授权进入 uncertain，不自动补扣或负债。一次账单仅允许一次 reserve/settle/refund/restore，已恢复结算后不能重放旧 refund。

## 外部模式的可执行授权边界

- 固定价格文本、图片、视频、音频，以及按确定输出秒数计价的视频可使用。
- 文本 Token 仅支持 `chat-completion`、`openai-response`、`claude-api`。模型必须显式声明上下文窗口与输出上限，预扣按整个上下文窗口的输入预算加输出上限保守报价，输入/缓存使用较高单价。冻结的输出上限会应用到 provider 请求；Agent 策略可以进一步缩小它。
- 同步代理必须提供该协议唯一有效的 `max_tokens` 或 `max_output_tokens`，缺少、冲突或协议不匹配均拒绝。
- 视频 Token 仅允许尺寸与时长确定、无参考视频的请求。参考视频时长在现有报价阶段尚不能从可信资源统一验证，暂拒绝此类外部计费。
- 按秒音频没有可执行的输出时长上限，外部模式暂拒绝；请使用固定价格音频。自定义文本协议无法证明输出上限映射时也拒绝。

这些拒绝发生在预扣和上游请求之前。内部钱包维持现有计费行为。
